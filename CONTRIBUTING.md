# Contributing to github-playground-lab

Thanks for contributing! This repo is intentionally designed to simulate open-source collaboration.

## Contribution rules

1. Create or pick an issue before starting work.
2. Create a focused branch (`feat/<issue>-name`, `fix/<issue>-name`, `docs/<issue>-name`).
3. Keep commits small and descriptive.
4. Open a PR using `.github/pull_request_template.md`.
5. Link the issue in your PR description (`Closes #<issue_number>`).
6. Address review feedback before merge.

## Branch naming examples

- `feat/21-add-cherry-pick-exercise`
- `fix/34-correct-rebase-guide`
- `docs/12-update-readme-roadmap`

## Commit message style

Use Conventional Commits where possible:

- `feat: add branching challenge`
- `fix: resolve merge conflict example`
- `docs: improve issue creation section`

## Pull request checklist

- [ ] Linked issue
- [ ] Clear summary of changes
- [ ] Tested locally (if applicable)
- [ ] Updated docs when needed

## Code review expectations

Reviewers should check:

- correctness
- clarity
- maintainability
- learning value for beginners
